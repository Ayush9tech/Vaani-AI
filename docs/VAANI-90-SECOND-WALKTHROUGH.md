## Before recording

- Use the sample profile, never a real resume containing private details.
- For the shortest live demo, show feedback after one answer, then use a prepared completed session for the progress screen.
- Enable microphone permission only when recording the voice demonstration on HTTPS or localhost. Check that your browser has the selected Hindi/English voice available.
- If no LLM key is configured, leave the “Demo rubric” labels visible. Do not describe those scores as a live model result.
- The phone call, NCS profile import/update, and peer comparison are explicitly simulated. No real phone number or government API is used.
- The badge is a self-assessment practice milestone, not an official certification or promise of employment.
